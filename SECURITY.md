# Security reporting

Do not report vulnerabilities containing exploit details, credentials, personal
information, or medical data in public issues.

Use this repository's **Security -> Report a vulnerability** private reporting
feature. Do not attach patient data even to a private report. For exposed
credentials, revoke/rotate them immediately with the service owner.

This repository contains a static, draft informational website. It is not an
enrollment, clinical screening, or medical-record system. Dependency alerts and
updates should be reviewed through tested PRs; never bypass branch protection
to apply a quick fix.
